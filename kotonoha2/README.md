# Kotonoha 双语阅读版

在既有 WebGAL 工程中提供第一至第三章中文／日文阅读。第三章 Ambivalence 含3-1至3-6；沿用语言与动效、大章、小节三级菜单。

第三章3-1结束播放OP，可跳过进入3-2；本章无ED。伴奏文件为`game/bgm/D.wav`，用于3-4战斗段；一次性音效不循环。浴前阿乌尔使用头发凌乱、脸衣干净的v2差分；3-6杰克与伊莱莎重聚站位已调整。人物同服装跨章共用资源，头像同源。

旧剧情路径与兼容资源保留。C3-4／3-5读档按稳定剧情标记或旧游标与精确正文定位；无法可靠定位时提示返回章节选择并保留原档。前两章旧档继续原路径，新菜单使用表情版路径。

## 本地运行

在仓库根目录运行`python -m http.server 8000`，访问`http://127.0.0.1:8000/kotonoha2/`。资源使用相对路径。

## 验证与限制

第三章双语正文共4342次段落重组比对通过；中日均完成整章连续推进，后续修订进行定点画面、读档、动效和媒体状态回归。手机为浏览器触控模拟，未做实体设备或物理扬声器听音测试。
