# 第一章日语配音

进入第一章每一节、开始原有预加载前，先询问是否“下载并播放本节日语配音”。首次默认勾选，之后记住上次选择；必须确认后才开始本节资源下载。勾选时，配音与画面、音乐共用原有三路下载队列、进度、重试和取消入口。不勾选时不请求配音清单或配音文件。

预加载按当前小节进行，不一次下载整个第一章。第 1-1 节为 79 条、约 12.0 MiB；最大小节 1-6 为 276 条、约 51.3 MiB。全章 938 条共 170.4 MiB，保留经过审计的原始 WAV，不另行转码。进度只在完整文件与配音哈希验证后计入成功；失败可重试或取消，也可关闭配音继续加载画面与音乐。

游戏内的配音开关和原有声音检查按钮均位于实际游戏画面内，跟随游戏缩放及旋转，不放在黑边。打开章节选择、游戏设置、回看或预加载菜单时隐藏悬浮控件。声音检查复用原游戏的测试音与解除静音逻辑；配音开关本身不改变背景音乐或音效。独立配音音量位于“配音设置”中。

关闭配音会立即停止当前声音、取消待完成配音请求和后续队列，并记住关闭选择。已缓存文件无需删除，关闭后仍不再请求或播放。预加载完成后仍按当前台词播放，不播放整节拼接音频；游戏内重新开启时只补取当前需要的台词。

938 个逐句 WAV 对应第一章 1-1～1-7，中日文本均播放日语。旁白和原定静默不配音。中文与日语分句不完全相同，中文段首顺序播放该段的日语短句；翻到下一文本片就取消余下短句，不跨页补播。自动模式等待当前配音队列；手动跳过、快进、菜单、切章、失焦或关闭开关会释放等待。

正式剧本、行数、场景路径和视觉资源保持不变。配音按原场景行号、原剧本 label 中的段落 ID 与屏幕文字交叉匹配，不依赖可能解析成 NaN 的 GameVar.koto_id；不匹配时静音。旧存档无需迁移。
